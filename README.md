# Qt 小游戏：大逃杀

高级程序设计课程（AP course）的课程项目，使用 C++ 和 Qt 6 编写的俯视角 2D 大逃杀小游戏。

玩家在一张会不断缩小的圆形地图上与多个敌人对战。身边环绕的火球既是护盾也是弹药，可以配合手雷、烟雾弹和草丛隐身，活到最后即可获胜。

## 玩法特色

- **惯性移动**：基于加速度、阻力和最大速度的移动手感，松开按键后会慢慢滑停。
- **火球护盾**：火球环绕在角色身边，可以抵挡攻击，也可以发射出去攻击敌人。被击中时先损失火球，没有火球才会掉血。火球会随时间自动补充，最多 10 个。
- **锁定追踪**：右键锁定附近的敌人后，发射的火球会自动追踪目标。
- **投掷物**：手雷可以对范围内的敌人造成伤害，烟雾弹可以制造一片能隐身的烟雾。
- **草丛隐身**：角色有一半以上进入草丛或烟雾时，敌人将无法发现你。
- **缩圈**：圆形安全区会持续缩小，圈外的角色会被推回圈内，圈外的道具会消失。
- **敌人 AI**：敌人会追击附近的玩家、主动拾取道具、在地图上游走，彼此之间也会互相攻击。
- **结算界面**：游戏结束后显示胜负、得分、排名和存活时间，可以选择重新开始或返回主菜单。

## 操作说明

| 操作 | 按键 |
|---|---|
| 移动 | `W` `A` `S` `D` |
| 发射火球 | 按下并松开鼠标左键 |
| 锁定敌人 | 鼠标右键 |
| 投掷手雷 | 按住 `X`，再点击鼠标左键 |
| 投掷烟雾弹 | 按住 `V`，再点击鼠标左键 |
| 冲刺闪避 | `空格` |
| 生成一个敌人 | 点击窗口左上角的敌人图标 |

## 道具

地图上每隔 3 秒会随机刷新一个道具：

| 道具 | 效果 |
|---|---|
| 爱心 | 回复 10 点生命 |
| 加速图标 | 手雷和烟雾弹各 +1 |
| 治疗图标 | 一段时间内提高移动速度 |
| 武器图标 | 火球 +5 |

## 构建与运行

### 环境

- Qt 6（开发时使用 Qt 6.9.0）
- 需要的 Qt 模块：`core`、`gui`、`widgets`、`multimedia`
- 支持 C++17 的编译器（开发时使用 MinGW 64-bit 和 MSVC 2022）

### 使用 Qt Creator（推荐）

1. 用 Qt Creator 打开 `game.pro`。
2. 选择一个 Qt 6 的构建套件（Kit）。
3. 点击运行。

### 使用 Visual Studio

安装 Qt VS Tools 扩展后，打开根目录下的 `game.sln` 进行构建。
